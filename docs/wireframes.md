# Product map

The original V0.1 wireframes have been promoted into the implemented product flow.

```text
Marketing site
  ├── Sign in / sign up demo entry
  └── Open workspace
         │
         ├── Overview
         ├── Projects
         ├── Import data
         │      └── CSV/XLSX upload or bundled demo
         ├── Semantic mapping
         │      └── mapping confidence + raw preview
         ├── Data quality
         │      └── score + explainable deductions
         ├── Analytics
         │      ├── KPI grid
         │      ├── revenue time series
         │      ├── category / region mix
         │      ├── product ranking
         │      └── deterministic insights
         ├── Reports
         └── Settings
```

Desktop is the primary target. The shell collapses progressively for smaller widths, while preserving the core data flow.
